# KalaSearch - Product Search App

Android application for searching products from Excel file

## Features:
- ✅ Fast search in products
- ✅ Data embedded in app (no internet needed)
- ✅ Search by: name, system code, old code, Part No

## Usage:
1. Install the application
2. Wait for data to load
3. Enter product name or code in search box

## Excel File Structure:
| Old Code | System Code | Product Name | Unit | Part No | Technical Spec |
|----------|-------------|--------------|------|---------|----------------|

## Build:
APK is available in GitHub Actions artifacts.
